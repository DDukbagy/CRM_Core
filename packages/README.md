# Packages — 공통 패키지

모노레포 내 공유 코드를 담는 디렉터리입니다.

```
packages/
├── api/   # 공통 API 클라이언트 유틸 (예정)
└── ui/    # 공통 UI 컴포넌트 (예정)
```

## api

`frontend`와 `apps/customer`가 공통으로 사용하는 API 클라이언트 유틸리티를 담을 예정입니다.

- 엔드포인트 정의
- 요청/응답 타입
- 인증 헤더 처리

현재는 각 앱의 `lib/api.ts`에 로컬로 구현되어 있으며,
중복이 늘어나면 이 패키지로 통합합니다.

## ui

`frontend`와 `apps/customer`가 공유하는 디자인 시스템 컴포넌트를 담을 예정입니다.

현재는 각 앱 내부에서 독립적으로 관리합니다.
